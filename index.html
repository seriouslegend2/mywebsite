02

Engineering signatures

Patterns that repeat
  1. 01

    Hunts silent failures

    The bug class I fix most is code that fails without erroring — a swallowed exception, a cached False with no TTL, an undeclared state key, an event dropped for a missing field, RLS on with no policies. Each fix ships instrumentation, so the class is visible the next time.

  2. 02

    Moves enforcement where it can't be bypassed

    When application checks proved leaky, the invariant moved down a layer — a trigger, a CHECK constraint, a partial unique index, a type constraint, or the absence of a tool. Make the bad state unrepresentable.

  3. 03

    Deletes aggressively, with evidence

    ~258k lines deleted against ~735k added, always gated on runtime evidence rather than static analysis — including removing a service the day after shipping it, and cutting 22,692 lines on a week of production evidence.

  4. 04

    Validates against production reality

    Fixes anchored to a real broken row and proved inside a transaction I then rolled back — not against synthetic data that agrees with the fix by construction.

  5. 05

    Writes the deploy order down

    Identifies when code and migration must land in a specific order, and flags the windows where database behaviour would outrun the application behaviour actually deployed.

  6. 06

    Configures through data, not code

    Decisions moved out of code and prompts into tables operators edit without a deploy: HITL settings, playbook tables, model routing, cohort bounds behind a kill switch.

  1. 01 Feb — May 2025

    Morld

    de-novo molecule generation

    Two-stage pipeline. Stage 1 trains an LSTM on 1M+ SMILES for next-token prediction. Stage 2 fine-tunes it with REINFORCE against a custom reward combining validity, novelty, fragment presence and QED. Top-p (nucleus) sampling for generation diversity, plus fragment-based control to steer toward a scaffold. An automated evaluation harness scores validity, novelty, uniqueness, diversity and QED.

    Results
    96% chemical validity · 100% novelty · 100% uniqueness · 0.85 QED
    Stack
    TensorFlow 2.19 · RDKit · Python 3.10 · LSTM · REINFORCE

  2. 02 Nov 2024 — Apr 2025

    Hunger Hearts

    food redistribution platform

    Moves surplus food from restaurants and households to families in slums, matching every donation to the nearest delivery partner with race-safe handoffs. Express + MongoDB behind a Next.js frontend, JWT auth with bcrypt. Redis on Upstash caches the post feed with write-through invalidation on new posts; MongoDB indexes cut query time. Swagger docs for every route at /api-docs, Jest unit tests, a Dockerised backend shipped to Docker Hub and deployed on Render via GitHub Actions, frontend on Vercel.
